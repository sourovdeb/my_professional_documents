# AI Explained Simply — Mindmap

`AI_Explained_Simply.mm` is a FreeMind/Freeplane-format interactive mindmap covering the
"AI Explained Simply" (Mistral Studio) lesson series.

- Open it with [FreeMind](https://freemind.sourceforge.io/) or [Freeplane](https://www.freeplane.org/) (free, cross-platform).
- Every node folds/unfolds interactively. Click a node's note icon to reveal its hidden
  speaker notes — the same content that backs the video/voiceover scripts.
- Covers Episode 1 (Agent) and Episode 2 (Model), which already have full scripts and
  slide decks in `AI_Term_Lessons/`, plus the roadmap of unwritten next episodes
  (Prompt, Token, Memory, Skill, Hook, Fine-tuning, RAG, JSON, Python) pulled from
  `AI_Term_Lessons/README.md`.
